# Projeto: Consumo de API com PHP - Dog API

## Descrição
Projeto desenvolvido para a disciplina Programação para Internet I, com o objetivo de consumir uma API pública (Dog API) utilizando PHP no back-end e HTML, CSS e JavaScript no front-end. A aplicação exibe imagens de cachorros e informações como raça e sub-raça, além de uma galeria com filtro por raça.

## Funcionalidades
- Consumo de API via PHP
- Exibição de imagem de cachorro aleatória
- Exibição de raça e sub-raça
- Botão de busca na página principal
- Galeria de imagens por raça
- Filtro por raça na galeria
- Botão "Voltar"
- Layout responsivo
- Tratamento básico de erros
- Tratamento básico de erros

## Tecnologias
- HTML
- CSS
- JavaScript
- PHP
- Dog API
